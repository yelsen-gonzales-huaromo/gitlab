# gitlab — Aprendiendo Git Flow de básico a experto

Repositorio de práctica. Cada tema se practica con commits y ramas reales.

## Progreso

### Nivel 1: Básico
- [ ] 1. Conceptos: commit, rama, merge, remoto
- [ ] 2. Comandos diarios: `add`, `commit`, `status`, `log`, `diff`
- [ ] 3. Ramas y merge simple

### Nivel 2: Git Flow clásico
- [ ] 4. Las 5 ramas: `main`, `develop`, `feature/*`, `release/*`, `hotfix/*`
- [ ] 5. Ciclo de feature, release y hotfix (a mano y con `git flow`)
- [ ] 6. Tags y versionado semántico

### Nivel 3: Intermedio
- [ ] 7. Conflictos de merge
- [ ] 8. `rebase` vs `merge`, `cherry-pick`, `stash`
- [ ] 9. Merge Requests en GitLab

### Nivel 4: Experto
- [ ] 10. `rebase -i`, `reflog`, `bisect`, `reset` vs `revert`
- [ ] 11. Protección de ramas y CI/CD
- [ ] 12. Git Flow vs GitHub Flow vs Trunk-Based
